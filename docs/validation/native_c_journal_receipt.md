The API caller received its original terminal reply 6,512.897 seconds after the first controller request. The caller then attempted to submit one JavaScript expression containing all 217 original tool replies. Platform review rejected that operation. The paired archive retains each original request and response, the final reply, the first denial, native resource measurements and the incomplete handoff.

The last complete tool return was exit 0. No producer binder, scientific auditor or final C verification ran. R3 left a second held scientific reader lease.
